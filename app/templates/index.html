Who is the Admin?

The System Administrator (Admin) is an authorized manager responsible for overseeing blood bank inventory, approving blood requests, verifying donor eligibility, and auditing security logs.

🔒 Security Policy: Admin accounts cannot be created publicly via a registration form. Admin credentials are created securely during system setup.
